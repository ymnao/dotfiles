# issue の書式

起票先の repo に `.github/ISSUE_TEMPLATE/` (または `.github/ISSUE_TEMPLATE.md`) があればそちらに従う。
無ければ本文を次の 4 節で書く:

```markdown
## 問題

## やること

## やらないこと

## 背景
```

- **問題** — 何が起きているか / 何が足りないか。観測した事実 (コマンドの出力・エラー文・該当箇所) と、それで困ること
- **やること** — 完了条件になる作業を `- [ ]` のチェックボックスで並べる。決まっていない判断は「〜するか決める」と書く
- **やらないこと** — スコープ外にするものと、その理由。別 issue に回すならそう書く
- **背景** — 起票のきっかけ・経緯・検討して捨てた案と捨てた理由

節に書くことが無ければ、節を消さずに「なし」と書く。
タイトルは何をするか / 何が問題かが 1 行で分かる平文にし、本文と同じ言語で書く。
